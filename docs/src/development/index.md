# Development Guide

This guide explains how to build, validate, extend, and investigate Atelier.
Beads owns live work state and dependencies; the reader-facing pages here
explain the current development contracts and preserve bounded historical
evidence.

- [Feature lifecycle](feature-lifecycle.md) — the dstack/Beads design,
  implementation, review, and close-out workflow.

  records retained for traceability.

## Historical evidence

Historical evidence pages are retained when they explain why a current contract
exists. They are labeled by date or release and must not be read as current
behavior unless the current architecture and tests confirm them.
