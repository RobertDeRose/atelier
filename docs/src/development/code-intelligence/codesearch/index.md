# Codesearch

Codesearch is Atelier's default semantic code provider. Atelier owns the
provider-neutral contract, capability checks, scope and revision identity,
budgets, bounded evidence, and reuse/invalidation decisions. Codesearch owns
its index and retrieval implementation.

- [Evaluation and conformance](evaluation.md) — current test isolation,
  provider contract, retrieval focus, and troubleshooting.
- [Evidence reports](evidence/index.md) — dated live-run and repair records.
