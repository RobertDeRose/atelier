# Legacy Decision Records

This archive preserves the pre-dstack decision documents that informed the
Atelier Core Foundation and later delivered features. They are historical
source material, not reader-facing architecture, live planning state, or an
additional authority. Current behavior is defined by the architecture overview,
reader-facing documentation, code, tests, and Beads.

The records remain available in this directory for migration traceability. The
[Atelier Core Foundation](../../../features/atelier-core-foundation/index.md)
and subsequent implemented-feature records reconcile their delivered intent.
