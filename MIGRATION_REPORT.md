# Migration Report — v0.10.0

No database or runtime configuration migration is required.

`atlr plan` and `/plan` now persist the normalized planning objective in the existing Atelier state
table. Existing repositories begin using this field the next time planning mode is entered. Working
State JSON gains task-selection, dependency, blocker, ManualEdit, retrieval-query, and richer code
evidence fields; consumers should ignore unknown fields or update their typed schema.

The legitimate Octocode 0.14.0 entry generated by `mise install` is now committed in `mise.lock`, so
a clean `mise install` should no longer modify the lockfile.
